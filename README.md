# Ритм просмотров каталога

Интерактивная визуализация для лабораторной работы № 3. Откройте `index.html` в браузере или включите GitHub Pages для корня ветки `main`.

Источник данных: [UCI Clickstream Data for Online Shopping](https://archive.ics.uci.edu/dataset/553/clickstream+data+for+online+shopping). На странице представлены агрегированные показатели за 18 полных недель 2008 года.
